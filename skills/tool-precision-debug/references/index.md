# Ascend C 精度调试知识库

按当前问题选择资料，具体使用条件见各页正文。

| 当前缺口 | 入口与读取范围 | 回答什么 |
| --- | --- | --- |
| 不知道下一步怎么定位 | [诊断方法](diagnosis/index.md)，选择观察点和对照实验 | 应该怎么查；结果能说明什么 |
| 不确定产品映射、架构能力、存储/执行模型或目标宏含义 | 使用 `/npu-arch` skill，按当前架构读取相关章节 | 平台能做什么；硬件资源和编程形态怎样对应 |
| 不确定具体 API 或调用语义，需要示例代码或类似算子 | 使用 `/ascendc-docs-search` skill，核对具体版本、产品和重载 | 接口规则是什么；怎样找到参考实现 |
| 已有异常，需要判断可能原因或参考类似问题 | [故障模式与案例](patterns/index.md)，按机制、算子或案例选择 | 哪些地方容易出错；怎样检查和修复 |

同一主题按用途取知：例如搬运的架构通路查 `/npu-arch`，DataCopy 参数与重载支持查 `/ascendc-docs-search`，观察设计查 diagnosis，尾块旧值的原因与排查方法查 patterns。

## 使用提示

使用经验前核对当前 CANN、NPU、输入和执行方式；案例中的成功结果不能替代本次验证。接口规则按目标版本查询，不自动套用最新文档或其他产品的结论。工具调用见[工具索引](../scripts/README.md)。
